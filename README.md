# PowerToys Roulette

A demo application that launches different PowerToys utilities via a roulette wheel interface.

## How to Run

1. Make sure you have [Rust](https://rustup.rs/) installed
2. Clone this repository
3. Run the application:
   ```bash
   cargo run
   ```

## Requirements

- Rust toolchain
- Windows OS
- PowerToys installed (optional, for full functionality)
